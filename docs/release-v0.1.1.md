家长空间新增手动应用更新：检查正式 GitHub Release、查看更新说明、下载新版、确认安装。

更新通过 139 服务器的 HTTPS 下载路径获取，服务器缓存 APK；下载站不可用时回退 GitHub。APK 在安装前校验 SHA-256、包名、版本和签名。

使用与首版相同的固定签名，支持直接覆盖安装并保留任务、星星、App 规则和家长 PIN。初次通过本应用安装更新时，需要在 Android 设置中允许「攒星星」安装应用；最终安装由 Android 系统确认。

本版本也包含每日任务、家长确认奖励、App 前台用量扣星、成长记录和本机数据导出。儿童记录只保存在本机，联网仅用于家长手动检查与下载更新。
